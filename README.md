# CreamClient 1.0 (Minecraft Forge 1.16.5)

Официальный репозиторий: https://github.com/sharagin/CreamClient-Minecraft

## Что нового
- Исправлен вылет в Multiplayer (безопасное определение биома и потокобезопасный Discord RPC).
- Милый ASCII-баннер в главном меню + кнопка-ссылка на GitHub.
- Чёрный игровой курсор с акцентной обводкой (`BlackCursor`).
- Стилизация инвентаря, сундуков и всех меню (`CustomMenus` -> `Style Inventory`).
- **Как поставить шрифт Terentiev SP Regular 400:** скачайте `.ttf` файл шрифта и замените им `src/main/resources/assets/creamclient/font/client_font.ttf` перед сборкой.
