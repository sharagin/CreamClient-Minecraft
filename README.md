# CreamClient 1.0 (Minecraft Forge 1.16.5)

Официальный репозиторий: https://github.com/sharagin/CreamClient-Minecraft

## Все визуалы и функции
- **Цветовые режимы (`Appearance -> ColorMode`)**: `Breathing`, `Rainbow` (переливание всего клиента и 3D-эффектов), `Static` + 7 палитр.
- **3D-визуалы**: `ParticleAura` (светлячки вокруг игрока), `HitParticles` (искры при ударе), `TargetRing` (кольцо вокруг цели), `BlockOverlay` (акцентная подсветка блоков), `ChinaHat`, `JumpCircles` (двойные кольца), `Trails`, `BoxESP`, `CustomFog`, `TimeChanger`, `NoWeather`, `ViewModel`, `Zoom [C]`.
- **HUD**: `Watermark`, `TargetHUD`, `SessionInfo`, `ScreenGlow` (свечение по краям), `Keystrokes + CPS`, `PotionHUD`, `ArmorHUD`, `Speedometer`, `CustomHotbar`, `Crosshair`.
- **Интерфейс**: `CreamMainMenuScreen` (созвездия + иконка GitHub), `CreamMultiplayerScreen`, `CreamOptionsScreen`, `CreamPauseScreen`, `BlackCursor`, языки `RU / EN / UK`, `DiscordRPC` и медиа-плеер.
