&lt;h2&gt;English&lt;/h2&gt;

&lt;p&gt;
  &lt;strong&gt;CreamClient v1.0&lt;/strong&gt; is a modular visual, cosmetic, HUD, and performance client for &lt;strong&gt;Minecraft Forge&lt;/strong&gt;.
  It features a bilingual (&lt;code&gt;RU / EN&lt;/code&gt;) Linux-style control panel (&lt;code&gt;Right Shift&lt;/code&gt;), &lt;strong&gt;100 unique 3D cosmetics&lt;/strong&gt;,
  configurable weak-PC optimization (&lt;code&gt;PotatoOptimizer&lt;/code&gt;), an interactive drag-and-drop UI constructor, a seekable &lt;code&gt;.wav&lt;/code&gt; music player with &lt;code&gt;MP4 &amp;rarr; WAV&lt;/code&gt; conversion, instant resource pack loading, and native Discord Rich Presence.
