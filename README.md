<h2>English</h2>

<p>
  <strong>CreamClient v1.0</strong> is a modular visual, cosmetic, HUD, and performance client for <strong>Minecraft Forge</strong>.
  It features a bilingual (<code>RU / EN</code>) Linux-style control panel (<code>Right Shift</code>), <strong>100 unique 3D cosmetics</strong>,
  configurable weak-PC optimization (<code>PotatoOptimizer</code>), an interactive drag-and-drop UI constructor, a seekable <code>.wav</code> music player with <code>MP4 &rarr; WAV</code> conversion, instant resource pack loading, and native Discord Rich Presence.
</p>

  </thead>
  <tbody>

      <td>11 tabs, global search across all modules, instant <code>RU / EN</code> toggle, per-module keybinder, <code>glScissor</code> smooth scrolling, UI sounds (<code>SoundFX</code>)</td>
    </tr>
    <tr>
      <td><strong>100 Unique 3D Cosmetics</strong></td>
      <td>Multi-layered 3D ears, horns, crowns, visors, wizard hats, ribbed wings, katanas, capes, jetpacks, 4-rotor drones, crystals, planets, pentagrams, DNA helices &amp; particles</td>
    </tr>
    <tr>
      <td><strong>Combat &amp; Hand Visuals</strong></td>
      <td><code>SmoothSwing</code> (5 fluid swing styles, speed, power), <code>HandVisuals</code> (X/Y/Z offset, 3D rotation, scale, item spin), <code>HitParticles</code>, <code>HitShockwave</code>, <code>DamagePopups</code></td>
    </tr>

    </tr>
    <tr>
      <td><strong>Waypoints &amp; Radar</strong></td>
      <td>3D beacon waypoints on <code>M</code>, automatic red <code>Death</code> waypoints (<code>DeathCoords</code>), proximity player radar (default <code>150m</code>) with toast &amp; sound alerts</td>
    </tr>
    <tr>
      <td><strong>Music &amp; Resource Packs</strong></td>
      <td>Seekable <code>.wav</code> player (<code>-10s/+10s</code>, click progress bar, <code>F7/F8/F9</code> hotkeys, menu mini-player), built-in <code>MP4 &rarr; WAV</code> converter, instant resource pack reload</td>
    </tr>
    <tr>
      <td><strong>Weak-PC Optimization</strong></td>
      <td><code>PotatoOptimizer</code>: live render distance (<code>2-16</code>), entity distance (<code>50%-100%</code>), particles, fast graphics, smooth lighting, clouds, mipmaps &amp; max FPS</td>
