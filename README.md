# CreamClient 1.0 (Minecraft Forge 1.16.5)

Кастомный клиент **CreamClient 1.0** для **Minecraft Forge 1.16.5** со встроенным логотипом, солнечным лаймовым фоном, новым ASCII-баннером, Discord Rich Presence, 3D-визуалами и полной кастомизацией через ClickGUI (`Right Shift`).

## Основные возможности
- **Discord Rich Presence (`DiscordRPC`)**: автоматически отображает статус игры (`CreamClient 1.0`, ник и сервер/одиночку) в Discord без сторонних DLL. Свой Application ID при желании можно указать в `.minecraft/config/creamclient.json` (`discordAppId`).
- **Готовый логотип и фон**: встроенный логотип и фон включены по умолчанию (`DefaultImage`), также можно переключать режимы (`Animated` / `CustomImage`) и кидать свои `.png`/`.jpg` в `.minecraft/creamclient/backgrounds/`, а `.wav` музыку в `.minecraft/creamclient/music/`.
- **Максимальная кастомизация**: правый клик в ClickGUI (`Right Shift`) открывает настройки радиуса/скорости `JumpCircles`, длины `Trails`, цветов тумана `CustomFog`, позиции руки `ViewModel`, 7 цветовых палитр (`Lime`, `Citrus`, `Mint`, `CyberCyan`, `Amethyst`, `Crimson`, `CreamGold`), переключения шрифта (`CreamHD` / `Vanilla`), прозрачности панелей и скорости анимаций.
